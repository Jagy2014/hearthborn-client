# Поиск метеоритов

Функция помогает определить **приблизительную область падения метеорита** по нескольким наблюдениям **Star Gaze**.

Каждое наблюдение задаёт направление или сектор. При сопоставлении нескольких секторов область поиска сужается. Учитывается прогнозируемое время падения.

Результат представляет собой **оценку зоны**, а не гарантированное местоположение метеорита.
