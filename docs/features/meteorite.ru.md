# Триангуляция метеорита

Когда появляется **уведомление о падающей звезде**, становится доступно действие **Star Gaze**. С его помощью можно определить направление предполагаемого падения метеорита.

## Как работает триангуляция

При каждом использовании **Star Gaze** Hearthborn рисует на карте указанное направление от точки, где было выполнено действие. Повторяйте **Star Gaze** в разных местах, чтобы добавить несколько линий направлений. Их пересечение помогает сузить вероятную область падения.

Пока событие звездопада активно, карта показывает ваши наблюдения, позволяя сравнивать направления и планировать поиски. Также можно ориентироваться на прогноз звездопада, предоставленный сервером.

## Управление линиями наблюдений

- **Пока событие активно:** линии направлений Star Gaze остаются на карте.
- **Удаление вручную:** нажмите **правой кнопкой мыши (RMB)** на точку карты, где использовали **Star Gaze**, чтобы удалить соответствующую линию.
- **После падения метеорита:** действие **Star Gaze** исчезает, а линии наблюдений автоматически удаляются с карты.

*Триангуляция помогает оценить область падения, но не показывает точное место удара.*
