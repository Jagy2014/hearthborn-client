# Cattle Roster

The **Cattle Roster** provides an overview of your recorded livestock in a redesigned, easier-to-read interface. Switch between animal categories using the illustrated tabs and review the attributes shown for each animal.

![Redesigned Cattle Roster with animal categories and attributes](../images/Cattle%20Roster.png)

## Managing animals

The roster includes controls to **select all**, **select none**, and **remove selected** entries.

### Automatically remove dead animals

Enable **Automatically remove dead animals** to keep the roster up to date. Animals that have died or been slaughtered are automatically removed from the roster, so you do not have to clean up their entries manually.
