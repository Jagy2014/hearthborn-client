# Поиск действий

Обновлённый **Action Search** помогает находить действия, рецепты и постройки без долгого просмотра меню.

- Поиск по названию действия, предмета или ингредиента.
- Избранные действия и история использования.
- Просмотр рецепта и необходимых материалов.
- Быстрый переход к нужному действию или строительству.
