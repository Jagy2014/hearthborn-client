# Переработанный поиск действий

Стандартный **Action Search** переработан в более удобный каталог действий. Теперь можно находить команды, не переходя по нескольким уровням меню, и сразу просматривать сведения о выбранном действии.

- Поиск по действиям, рецептам изготовления и строительству.
- Переключение между **Favorites** и **History**.
- Добавление часто используемых действий в избранное.
- Просмотр пути к действию в меню, а для поддерживаемых рецептов — ингредиентов и сведений об изготовлении.
- **Search by ingredient** для поиска рецептов по материалам.
