# Переработанная карта и экспорт

Система карт переработана, включая сохранение исследованных участков и обмен картографическими данными между клиентами.

- **Экспорт и импорт данных карты** для переноса исследованной карты в другой клиент.
- **Экспорт карты как изображения** для обмена или справки.
- **Экспорт тайлов карты**, если нужны изображения отдельных клеток карты.
- Нет отдельного режима записи на диск: лишняя постоянная запись данных исключена.
