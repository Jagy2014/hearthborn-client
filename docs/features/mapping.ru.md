# Карта и экспорт

Система карт переработана для удобного использования и переноса исследованных территорий.

- **Экспорт и импорт данных карты** между клиентами.
- **Экспорт изображения карты** для обмена и справки.
- **Экспорт отдельных тайлов** карты.
- Без отдельного режима постоянной записи данных на диск.

Экспортируются только данные, которые уже известны клиенту. Неисследованные территории не раскрываются.
