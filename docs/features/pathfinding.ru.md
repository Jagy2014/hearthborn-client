# Улучшенный поиск пути

Hearthborn упрощает обход препятствий при повседневном передвижении.

- **Пешком:** поиск пути включён по умолчанию.
- **Shift + щелчок:** временно обходит поиск пути.
- **Настройки:** позволяют полностью отключить эту функцию.
- **Верхом:** поддерживается отдельный режим поиска пути, **выключенный по умолчанию**.
- **Исключения:** функция не применяется в бою, при плавании или движении на лодке.

Алгоритм не гарантирует, что персонаж сможет преодолеть любое препятствие.
