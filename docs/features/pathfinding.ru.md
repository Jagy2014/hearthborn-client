# Улучшенный поиск пути

Hearthborn перерабатывает стандартный поиск пути, чтобы повседневное перемещение было удобнее и меньше мешало игре. При движении пешком функция **включена по умолчанию**. Её можно отключить в настройках или временно обойти сочетанием **Shift+щелчок**.

- Автоматически обходит ближайшие препятствия, не мешая обычному управлению.
- **Не используется во время боя, при плавании или путешествии на лодке.**
- **Поиск пути верхом** поддерживается, но по умолчанию выключен; его нужно отдельно включить в настройках.
