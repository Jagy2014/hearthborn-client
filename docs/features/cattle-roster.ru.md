# Журнал животных (Cattle Roster)

**Cattle Roster** показывает записанных животных в переработанном, более удобном интерфейсе. Переключайтесь между категориями животных с помощью вкладок с картинками и просматривайте отображаемые характеристики каждого животного.

![Обновлённый журнал животных с категориями и характеристиками](../images/Cattle%20Roster.png)

## Управление списком

В журнале есть команды **Select all** (выбрать всех), **Select none** (снять выделение) и **Remove selected** (удалить выбранных).

### Автоматическое удаление погибших животных

Включите **Automatically remove dead animals**, чтобы журнал автоматически удалял записи о животных, которые погибли или были забиты. Больше не нужно вручную очищать список от таких животных.
